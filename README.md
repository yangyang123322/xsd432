纯静态，无需服务器：双击 `index.html` 即可（数据内嵌在 `data/data.js`，KaTeX 已本地化，断网也能用）。所有个人记录（收藏、错题、复习进度、默写勾选、主题）只写本机 `localStorage`，不上传。

## 三、体系逻辑（和数砖对齐的四层）

1. **数据层**：题目是一等公民。每题五维标注（考点 / 知识模块 / 教材 / 能力层级 / 题型分值），并附解题、易错点、延伸、两道同源适配题。
2. **索引层**：两轴正交。轴一按考纲章节走（"目录是一棵树"），轴二按解题招法走（"解题是一张网"）。同一道题在两轴上各出现一次，互为入口。
3. **闭环**：错题 → SM-2 复习 → 诊断 → 弱考点 → 回两轴。诊断按**提分期望**排序，不是按错题数。
4. **反馈**：数据缺口显式呈现，见下。

## 四、数据缺口（已知、未伪造）

- 结构上八套卷共 **118 题**，本站收录 **111 题**，缺 7 题（2025 名词解释 5→3、填空 5→2；2022 填空 5→3）。原因是《教研分析》这几段没有逐题拆解，不是抓取漏题。

## 八、在手机上看

两条路，按需选：

| 方式 | 怎么用 | 适合 |
|---|---|---|
| 单文件 `mobile.html` | 传到手机（微信文件传输助手／OneDrive／数据线），用浏览器打开 | 通勤、床上、断网；只读＋打卡 |
| `手机访问.bat` | 双击启动本机服务，手机连同一 WiFi 打开 `http://<电脑IP>:8000/` | 要用题库、模考、搜索等全部功能 |

`mobile.html` 的进度存在手机浏览器本地（localStorage），和电脑上各记各的——用页面里的 **⇅ 进度同步** 按钮把两边接上（见下）。
### 进度同步（⇅）

电脑站右下角、手机版搜索框右边各有一个 **⇅** 按钮，用来在两台设备之间搬「已学会 / 默写会了 / 题库记录」：

1. 在 A 设备点 ⇅ → 「生成本机进度码」→ 复制那一行 JSON；
2. 微信发到 B 设备，粘进同一个框 → 「合并并刷新」；
3. 合并只增不减（并集），不会把 B 上已经打过的勾删掉。

码的格式：`{"v":1,"ts":"...","L":["j05"],"Z":["3"],"Q":{"2026-1":{"done":1}}}` —— L 是招法 id、Z 是默写编号、Q 是题库状态。
## 九、云同步（可选，自动双向）

单文件版和桌面版都内置了「云同步」：把进度存进你自己的一个**私密 Gist**，两台设备用同一个 token，之后每次改动（标记已学会 / 默写 / 题库）约 2 秒上传，打开页面自动拉取合并。

**怎么开**

1. GitHub → Settings → Developer settings → Personal access tokens → **Fine-grained tokens** → Generate new token
2. 只勾一项：**Account permissions → Gists → Read and write**（其它全部 No access），有效期自选
3. 复制生成的 `github_pat_…`
4. 打开站点 → 点 **⇅** → 在「云同步」框里粘进去 → **连接并同步**
5. 另一台设备重复第 4 步（粘同一个 token）——它会自动找到同一个 gist 并合并

**规则**

- 合并只增不减：两边的「已学会」取并集，不会互相覆盖
- token 只存在本机 localStorage，不写进页面源码，也不上传到别处
- 担心泄漏就随时在 GitHub 撤销该 token，页面里点「断开云同步」即可
- 不想用云同步也行：⇅ 面板里的「同步链接」一条 URL 就能手动同步，零账号零风险

**代码位置**

- 桌面版：`assets/app.js` 里的 `U.cloud`（`U.set` 会在 learned/quiz/qstate 变化时调 `pushLater`）
- 手机版：`build/mobile_app.js` 里的 `cloud`（`LS.set` 变化时调 `pushLater`）
- 两端 gist 文件名固定 `xsd432-progress.json`，description 固定 `xsd432-progress`（用来跨设备认领同一个 gist）
